# Гармония — личный онлайн-учебник

Публичный **код интерфейса**, закрытая библиотека в Supabase. Исходная программа — **24 отдельных урока**, одна крупная тема на урок. Уроки не объединяются по фактическим встречам с преподавателем.

## Реализовано в интерфейсе

- Тёплая графитовая тема без синего, адаптация к планшету и телефону.
- Курс, страницы уроков, библиотека последовательностей, избранное, заметки и отметки прогресса.
- Два нотных стана в SVG; аккорды и широкие арпеджио; кнопки транспонирования и выбор тональности.
- Единая модель высот для нот, звука и MIDI. Сохранение написания вводных тонов, обращений и заданного баса.
- Проигрывание в браузере: синтезированный звук, темп, повтор, отдельные руки, MIDI-экспорт.
- Прямой REST-клиент Supabase Auth; вход по ссылке / email OTP при соответствующей настройке Auth.
- Закрытый доступ по серверным правилам RLS, без публикации материалов в HTML или JS.

## Статус первой версии

Интерфейс и тесты готовы. `site/config.json` намеренно не содержит реквизитов проекта. Пока конфигурация пуста, кнопка входа отключена, личные материалы недоступны. Никакого публичного демо с приватными уроками нет.

База, подтверждённый пользователь, SMTP / письмо входа и RLS должны быть настроены и проверены до заявления о готовности приватного доступа. Схема в `supabase/schema.sql` — подготовленный SQL, не признак уже созданного проекта.

## Локальная работа

Нужен Node.js 22 или новее, для простого сервера — Python 3. Внешних npm-зависимостей нет.

```sh
npm test
npm run build
npm start
```

Сервер: `http://localhost:4173`. Сборка копирует **только** каталог `site` в `dist`.

## GitHub Pages

Один раз: Settings → Pages → Build and deployment → Source: **GitHub Actions**.

Workflow проверяет музыкальную модель, собирает публичный интерфейс и публикует при изменениях в `main`. Последующие публикации не требуют ручного нажатия кнопки Deploy. Создание Pages может требовать разовой административной настройки, которую файловое подключение не выполняет.

## Подключение закрытой библиотеки

1. Создать отдельный Supabase-проект после согласования организации и стоимости.
2. Применить `supabase/schema.sql` с правами администратора. Непубличный контент не импортировать через CI.
3. Создать пользователя в Supabase Auth, подтвердить его адрес, добавить **проверенный UUID** в `public.members`. Отключить свободную регистрацию и анонимный вход.
4. Импортировать подготовленные личные уроки и упражнения в базу с этим `owner_id`. Не коммитить seed с личными материалами в репозиторий.
5. В Auth задать Site URL / Redirect URL адрес GitHub Pages, настроить почту. Письмо со ссылкой подходит без изменения шаблона; код требует соответствующего email-шаблона и доступного SMTP.
6. В `site/config.json` записать только URL проекта и активный **publishable key**. Никогда не публиковать `service_role`, secret key или пароли.
7. Проверить три случая: анонимный посетитель не читает таблицы; другой подтверждённый пользователь не читает материалы; владелец читает и сохраняет только свои записи. Запустить Supabase Security Advisors.

## Формат данных

Урок: `id`, `position`, `chapter`, `chapter_title`, `title`, `subtitle`, `goal`, `preparation[]`, `topics[]`, `owner_id`.

Упражнение: `id`, `lesson_id`, `position`, `title`, `goal`, `discuss`, `mode`, `progression[]`, `loop`, `owner_id`.

Элемент progression: обозначение аккорда или объект `{symbol, bass?, beats?, offset?, mode?}`. `bass` — ступень фиксированного баса; `offset` — новая тоника в полутонах от исходной при модуляции. Ступеневые бемоли всегда отсчитываются от одноимённого натурального мажора. `vii°7` в миноре строится на повышенной VII, `K64` учитывает лад.

## Ограничения

Это учебная нотная запись аккордов и арпеджио, не полноценный редактор партитур. В первой версии нет перетаскивания нот, анализа голосоведения и живого подключения MIDI-клавиатуры. Звук синтезированный, не записанные сэмплы рояля. MIDI-файлы экспортируются; реальная отправка писем и доступ к Supabase требуют отдельной проверки после подключения проекта.

Прогресс из чатов не отмечается автоматически. Все уроки остаются отдельными темами в первоначальном порядке.


### Басовые линии внутри такта

Для упражнений с самостоятельной партией левой руки используется поле `exercise.theory.notation.bass_line`: массив тактов, в каждом такте — события `{degree:"1",duration:1}`, `{degree:"#4",duration:.5}` или `{rest:true,duration:.5}`. Сумма длительностей должна совпадать с метром; поддержаны 0.5, 1, 1.5, 2, 3 и 4 четвертные доли. Необязательный `octave` сдвигает звук на октаву, `semitones` фиксирует регистр относительно тоники (с проверкой соответствия ступени). Правая рука, нотная запись, плеер и MIDI используют одну событийную модель. Содержимое учебника хранится в закрытой базе Supabase.
